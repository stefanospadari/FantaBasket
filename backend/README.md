### La directory backend corrisponde esattamente alla directory src di un progetto Eclipse

Sul repository metto solo questa cartella per non stare a mettere tutto il progetto Eclipse, tanto solamente la cartella src è l'unica che subisce dei cambiamenti interessati
La parte di frontend è interamente spostata nella cartella frontend e non si trova nel progetto Eclipse

Per usarla basta fare git pull dell'intero repository e copiare la cartella backend in quella src del progetto in cui si vuole lavorare
Per ricaricarla sul repo copiare dal progetto la cartella src all'interno della cartella backend e fare git push
